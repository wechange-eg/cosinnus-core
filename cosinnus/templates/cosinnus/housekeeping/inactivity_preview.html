This page is read-only and shows the objects affected if the inactivity jobs run now.

Warning counts include only candidates whose configured warning date is today; candidates between warning dates are not included. In contrast, deactivation counts include all candidates whose inactivity period has elapsed and who have not yet been scheduled for deletion.

  • Missed warnings are not retried. Shortening inactivity periods can deactivate overdue accounts or groups without prior warning.
  • Counts use stored activity dates; this preview does not refresh Rocket.Chat or Nextcloud activity. Group counts are not email counts and may include groups without admins.
  • Babel rounds durations to the configured unit. Check wording in every language manually; missing language branches are not detected.
  • Emails use example data and are shown without the final HTML mail layout.
  • Dry run applies only to inactivity warning and deactivation jobs, not to already scheduled deletions or activity updates.
